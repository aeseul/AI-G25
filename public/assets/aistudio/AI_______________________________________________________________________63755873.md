# AI 편의점 꿀조합 큐레이터
## Google AI Studio Build 모드용 MD 개발 프롬프트
### 레트로 주니어 게임 감성의 인터랙티브 가상 GS25 월드 구현

> **목표**
> 기존 앱에 일반적인 상품 목록 화면을 하나 더 추가하는 것이 아니라, 사용자가 `가상 편의점 입장하기` 버튼을 누르면 작은 2.5D 아이소메트릭 게임 월드가 열리고, 편의점 안의 진열대·냉장고·행사 코너·전자레인지·계산대 등을 직접 클릭해 상품을 탐색하고 구매 과정을 체험하도록 만든다.
>
> **중요:** 이 문서는 기존 Google AI Studio 프로젝트를 수정하기 위한 프롬프트다. 프로젝트를 새로 만들거나 기존 코드를 초기화하지 말고, 현재 앱의 구조와 디자인을 분석한 뒤 기존 기능에 이어서 구현한다.

---

# Google AI Studio에 입력할 개발 프롬프트

너는 React, TypeScript, CSS 및 SVG 기반 인터랙티브 웹 애플리케이션을 개발하는 시니어 프론트엔드 개발자이자 게임 UI/UX 디자이너다.

현재 개발 중인 앱은 **「AI 편의점 꿀조합 큐레이터」**다. 기존 앱의 로그인, 사용자 조건 입력, 주변 편의점 검색, 매장 선택, AI/샘플 추천 결과, 레시피 등 이미 구현한 기능을 유지하면서, 사용자가 선택한 매장 다음 단계에 **레트로 주니어 게임 감성의 가상 편의점 월드**를 추가하라.

사용자가 앱에서 가상 편의점 버튼을 누르면 마치 옛날 온라인 주니어 게임의 집이나 상점 안으로 들어가는 것처럼 새로운 공간이 열려야 한다. 사용자는 화면 속 편의점 내부를 둘러보고, 진열대·냉장고·계산대 등 오브젝트를 클릭해 상품 정보를 확인하고 장바구니에 담을 수 있어야 한다.

## 1. 가장 중요한 디자인 목표

### 원하는 시각적 분위기

사용자가 제공한 참고 이미지에서 다음 특징을 시각적 방향으로 삼는다.

- 옛날 온라인 주니어 게임처럼 작은 공간을 탐험하는 느낌
- 위에서 비스듬히 내려다보는 아이소메트릭(Isometric) 시점
- 바닥과 양쪽 벽이 함께 보이는 2.5D 공간
- 귀엽고 따뜻한 파스텔 컬러
- 작은 캐릭터가 공간 안에 존재하는 게임 월드
- 진열대, 테이블, 냉장고, 계산대 등 오브젝트를 직접 클릭하는 경험
- 장면 안에서 클릭 가능한 곳이 자연스럽게 눈에 띄는 인터랙션

**중요한 차이:** 참고 이미지의 특정 게임 캐릭터, 상점 디자인, 로고, 워터마크 또는 화면 구성을 그대로 복제하지 않는다. 이미지들은 분위기와 시점의 참고 자료로만 사용하고, AI 편의점 꿀조합 큐레이터만의 독창적인 가상 편의점 세계관을 만든다.

### 전체 미술 방향

- 스타일: 귀여운 레트로 주니어 게임 + 현대적인 한국 편의점
- 공간: 아이소메트릭 2.5D 편의점 내부
- 메인 컬러: GS25를 연상시키는 그린과 화이트, 따뜻한 크림색
- 보조 컬러: 파스텔 민트, 라이트 옐로, 오렌지
- 포인트: 행사 상품과 클릭 가능한 오브젝트는 밝은 색으로 강조
- 질감: 부드러운 그림자, 둥근 모서리, 작은 디테일
- 캐릭터: 앱 전용 오리지널 미니 캐릭터 또는 아바타
- 화면은 귀엽지만 유치하지 않게, 실제 편의점의 상품 진열 구조를 알아볼 수 있게 표현한다.

게임 참고 이미지를 그대로 쓰거나 외부 이미지의 워터마크가 남은 자료를 사용하지 말고, 자체 SVG/CSS 일러스트 또는 프로젝트의 사용 가능한 이미지 자산을 활용한다.

## 2. 기존 앱 흐름을 유지하고 가상 월드로 연결

기존의 사용자 이용 흐름을 다음과 같이 연결한다.

```text
로그인 / 회원가입
        ↓
기존 메인 화면
        ↓
위치 기반 주변 편의점 탐색
        ↓
매장 선택
        ↓
[가상 편의점 입장하기] 버튼
        ↓
가상 편의점 외부 입구 화면
        ↓
[문 열고 들어가기] 인터랙션
        ↓
아이소메트릭 가상 편의점 내부
        ↓
진열대·냉장고·행사 코너 등 클릭
        ↓
상품 상세 패널 및 장바구니
        ↓
예산에 맞는 꿀조합 추천
        ↓
레시피 / 가상 구매 / 영수증
```

### 진입 버튼

기존 매장 선택 화면에서 매장을 선택한 후 다음 버튼을 제공한다.

**버튼명: `가상 편의점 입장하기`**

버튼을 누르면 일반적인 상품 리스트 페이지로 이동시키지 말고, 게임 월드에 들어가는 듯한 전환 효과를 구현한다.

- 짧은 페이드 또는 줌인 전환
- 매장 간판이 보이는 외부 입구 화면
- `어서 오세요! 오늘의 한 끼를 골라볼까요?` 안내
- `문 열고 입장하기` 버튼 또는 문을 직접 클릭하는 영역

문을 클릭하면 매장 내부가 열리도록 한다.

### 매장 표시 정보

- 브랜드: GS25 (가상 시뮬레이션)
- 선택된 매장명: 앞 화면에서 전달된 매장명
- 내부 데이터 ID: `GS25_DEMO_001`
- 상태 표시: `가상 매장 체험 중`
- 안내 문구: `상품·가격·행사·재고는 앱 테스트용 가상 데이터입니다.`

선택한 실제 매장명과 가상 매장 데이터가 혼동되지 않도록 항상 가상 매장 안내를 표시한다.

## 3. 가상 편의점 월드의 공간 구성

### 전체 장면

화면 중앙에 하나의 큰 아이소메트릭 편의점 내부를 배치한다.

공간이 실제 편의점처럼 보이도록 다음 오브젝트를 표현한다.

1. 입구와 자동문
2. 중앙 상품 진열대 2~3개
3. 라면 및 간편식 진열 구역
4. 음료 냉장고
5. 냉장식품 및 유제품 코너
6. 행사 상품 진열대
7. 전자레인지 및 온수기 코너
8. 계산대
9. 장바구니 또는 쇼핑 바구니
10. 작은 캐릭터 또는 매장 안내 직원

모든 오브젝트는 공간의 원근과 크기에 맞게 배치한다. 상품 진열대에는 작은 패키지 형태의 상품들이 보이게 하되, 세부 텍스트가 읽히지 않아도 상품 카테고리를 시각적으로 구분할 수 있어야 한다.

### 공간 레이아웃 예시

```text
        ┌──────────── 매장 후면 벽 ────────────┐
        │  음료 냉장고       냉장식품      행사 코너 │
        │                                      │
        │      [중앙 진열대 A] [중앙 진열대 B]   │
        │                                      │
        │  라면/간편식 코너       전자레인지/온수기 │
        │                                      │
        │  입구/자동문             계산대/바구니   │
        └──────────────────────────────────────┘
```

이는 배치 참고용이다. 실제 렌더링은 아이소메트릭 시점에 맞춰 바닥과 벽이 함께 보이는 입체 공간으로 만든다.

## 4. 반드시 클릭할 수 있어야 하는 오브젝트

단순히 예쁜 배경 그림만 만들면 안 된다. 편의점 내부의 주요 오브젝트마다 실제 클릭 영역을 구현해야 한다.

### A. 라면·간편식 진열대

클릭하면 라면 및 간편식 상품 패널이 열린다.

- 불닭볶음면
- 육개장 사발면
- 삼각김밥 등

패널에는 상품 이미지/아이콘, 상품명, 가격, 행사 여부, 가상 재고, `장바구니 담기` 버튼을 표시한다.

### B. 냉장고

클릭하면 음료와 유제품 카테고리 패널을 연다.

- 바나나우유
- 생수 500ml
- 스트링치즈 등

냉장고 문이 살짝 열리는 애니메이션 또는 밝기 변화 등 가벼운 반응을 준다. 실제 문 열기 물리 시뮬레이션은 필요하지 않다.

### C. 행사 상품 코너

클릭하면 1+1 / 2+1 상품만 모아서 보여준다.

- 행사 배지
- 정상 가격
- 행사 조건
- 행사 적용 가격
- 적용 수량 안내

행사 계산은 코드에서 수행한다. 예시 데이터는 실제 GS25 행사 정보가 아님을 표시한다.

### D. 전자레인지·온수기 코너

클릭하면 조리 안내 패널이 열린다.

- 전자레인지 사용 가능 상품
- 온수 사용 상품
- 간단 조리 가이드
- 상품 포장지의 조리 안내 우선 문구

### E. 계산대

클릭하면 장바구니와 예산 계산 화면을 연다.

- 선택 상품 목록
- 수량 변경
- 행사 할인
- 총 예상 금액
- 설정 예산
- 남은 잔액
- `가상 구매 완료` 버튼

실제 결제는 구현하지 않는다.

### F. 쇼핑 바구니

클릭하면 현재 장바구니 요약을 작은 패널로 연다. 상품을 추가할 때 바구니의 상품 수량이 즉시 바뀌고, 장바구니 아이콘에 수량 배지를 표시한다.

### G. 안내 캐릭터

작은 오리지널 캐릭터를 매장 내부에 배치한다. 클릭하면 이용 방법을 알려주는 말풍선이 나온다.

예:
- `라면 코너를 눌러 상품을 살펴보세요!`
- `행사 코너에서 1+1 상품을 확인해 보세요.`
- `5,000원 안에서 장바구니를 완성해 보세요!`

캐릭터는 장식만이 아니라 초보 사용자의 탐색을 도와주는 가이드 역할을 한다.

## 5. 클릭 인터랙션과 게임 요소

### 오브젝트 반응

사용자가 오브젝트에 마우스를 올리거나 클릭하면 다음 효과를 준다.

- Hover: 살짝 커지거나 밝아짐
- 클릭: 짧은 눌림 애니메이션
- 선택된 오브젝트: 초록색 외곽선 또는 반짝임
- 패널 열기: 오른쪽 또는 하단에서 부드럽게 등장
- 패널 닫기: X 버튼 또는 바깥 영역 클릭
- 키보드 접근성: Tab으로 오브젝트 이동, Enter/Space로 열기

각 클릭 영역은 실제 그래픽 위에 투명한 SVG 또는 HTML hotspot으로 배치한다. 클릭 위치와 시각적 오브젝트가 일치해야 한다.

### 작은 캐릭터 이동

가능하면 매장 안에 작은 캐릭터를 배치하고, 사용자가 진열대나 냉장고를 클릭하면 캐릭터가 해당 위치 쪽으로 이동하는 간단한 애니메이션을 넣는다.

- 복잡한 경로 탐색이나 물리 엔진은 사용하지 않는다.
- 클릭한 목표 위치로 CSS transition을 이용해 부드럽게 이동한다.
- 모바일에서는 캐릭터 이동이 인터랙션을 방해하지 않도록 한다.
- 모션 감소 설정을 사용하는 사람에게는 애니메이션을 줄인다.

### 게임 HUD

게임 화면 상단 또는 하단에 다음 정보를 고정한다.

- 현재 매장명
- `가상 매장` 배지
- 현재 예산
- 장바구니 상품 수
- 현재 장바구니 금액
- 남은 예산 게이지
- `홈으로`, `추천받기`, `장바구니` 버튼

예산 게이지는 상품을 장바구니에 담을 때 실시간으로 변한다.

### 미션 요소

화면 한쪽에 작은 미션 카드를 배치한다.

**오늘의 미션: 5,000원으로 한 끼 완성하기**

- [ ] 상품 2개 이상 선택하기
- [ ] 5,000원 이하로 맞추기
- [ ] 레시피 확인하기
- [ ] 가상 구매 완료하기

미션을 완료하면 별 또는 스탬프 애니메이션을 보여준다. 게임 포인트는 장식적인 보상이며 실제 금액이나 결제 혜택과 혼동되지 않게 한다.

## 6. 상품 데이터 및 기능 연결

기존 프로젝트에 이미 `gs25SampleCatalog.ts`, 상품 타입, 가격 계산 유틸리티, 이미지 유틸리티가 존재할 수 있다.

**새 상품 데이터베이스를 무조건 별도로 중복 생성하지 않는다.**

먼저 기존 프로젝트를 확인하고 다음 원칙을 적용한다.

1. 기존 상품 타입과 카탈로그를 우선 재사용한다.
2. 기존 `formatKRW`, 가격 계산 서비스, 상품 이미지 함수를 재사용한다.
3. 가상 매장 오브젝트는 기존 상품 카테고리 또는 상품 ID와 연결한다.
4. 기존 추천 결과와 새 가상 매장 장바구니가 같은 상품 ID를 사용하도록 한다.
5. 상품이 기존 DB에 없을 때만 필요한 데모 상품을 추가한다.
6. 상품·가격·행사·재고가 모두 `DEMO` 데이터임을 표시한다.

### 초기 데모 상품 예시

기존 상품 카탈로그에 해당 데이터가 없다면 아래 예시를 추가한다.

| ID | 상품명 | 카테고리 | 예시 가격 | 초기 가상 재고 |
|---|---|---|---:|---:|
| P001 | 불닭볶음면 | 라면 | 1,800원 | 10 |
| P002 | 육개장 사발면 | 라면 | 1,200원 | 8 |
| P003 | 참치마요 삼각김밥 | 간편식 | 1,200원 | 12 |
| P004 | 전주비빔 삼각김밥 | 간편식 | 1,200원 | 10 |
| P005 | 스트링치즈 | 유제품 | 1,500원 | 7 |
| P006 | 훈제란 1구 | 계란 | 1,000원 | 9 |
| P007 | 바나나우유 | 음료 | 1,500원 | 6 |
| P008 | 생수 500ml | 음료 | 800원 | 15 |
| P009 | 초코바 | 간식 | 1,000원 | 10 |

이 가격은 개발 시뮬레이션용이며 실제 GS25 판매 가격을 뜻하지 않는다.

### 행사 예시

- 바나나우유: 가상 1+1
- 초코바: 가상 2+1
- 나머지 상품: 행사 없음

행사 할인은 수량 조건에 따라 코드에서 계산한다.

### 재고 예시

- 5개 이상: 재고 있음
- 1~4개: 소량 재고
- 0개: 품절

사용자가 장바구니에 상품을 담을 때 가상 재고 수량을 검증한다. 가상 구매가 완료되면 로컬 시뮬레이션 재고만 차감한다.

실제 GS25 매장 재고나 실제 결제에는 어떠한 영향도 주지 않는다.

## 7. 예산과 추천 기능 연결

가상 매장 월드에서 상품을 담은 후에는 기존 앱의 추천 기능과 자연스럽게 연결한다.

### 예산 HUD

기본 예산은 5,000원으로 설정한다.

```text
내 예산      5,000원
장바구니     3,300원
남은 금액    1,700원
```

상품을 추가하거나 수량을 바꾸면 즉시 계산한다.

`남은 예산 = 설정 예산 - 행사 적용 후 총 결제 예상 금액`

가격 합산 및 행사 적용은 Gemini가 아니라 기존 가격 계산 코드 또는 별도 pricing service에서 수행한다.

### 꿀조합 추천 버튼

가상 매장 내부 HUD에 `내 예산으로 꿀조합 찾기` 버튼을 둔다.

버튼을 누르면 기존 추천 입력/추천 결과 화면으로 이어진다.

- 사용자가 선택한 예산 전달
- 선택한 매장명 전달
- 맛 테마 및 식사 상황 전달
- 현재 가상 상품 데이터 전달
- 추천 결과와 가격 검증
- 상세 레시피 및 장바구니 연결

Gemini API가 사용 불가능한 경우 기존의 데이터 기반 대체 추천 또는 규칙 기반 추천을 사용한다. 가상 월드의 핵심 인터랙션은 Gemini 유료 API 없이도 작동해야 한다.

## 8. 상품 상세 패널 디자인

오브젝트를 클릭하면 전체 화면을 다른 페이지로 이동시키지 말고, 가급적 같은 게임 공간 위에 상세 패널을 띄운다.

### 패널 예시

```text
┌──────────────────────────────┐
│ 라면 진열대              [X] │
│                              │
│  🍜 불닭볶음면                │
│  1,800원                     │
│  가상 재고 10개              │
│                              │
│  [수량 -] 1개 [수량 +]        │
│                              │
│  [장바구니에 담기]            │
└──────────────────────────────┘
```

패널은 다음 내용을 포함한다.

- 선택한 코너 이름
- 상품 이미지 또는 카테고리 일러스트
- 상품명 및 가격
- 행사 배지
- 가상 재고
- 수량 조절
- 장바구니 담기
- 닫기 버튼

상품을 담으면 작은 `장바구니에 담았어요!` 알림과 바구니 숫자 변경을 보여준다.

## 9. 데스크톱과 모바일 반응형

### 데스크톱

- 가상 편의점 공간을 화면 중앙에 크게 배치
- 상단 HUD와 하단 퀵 메뉴
- 오브젝트 클릭 영역은 충분히 크게
- 상품 상세 패널은 오른쪽에 나타나도록 구성

### 모바일

- 아이소메트릭 월드는 가로 비율을 유지하면서 화면 너비에 맞게 축소
- 오브젝트 클릭 영역은 손가락으로 누를 수 있도록 충분한 크기로 설정
- 상품 패널은 하단 바텀시트로 열기
- 예산과 장바구니는 상단 또는 하단에 고정
- 화면이 좁아지면 장식 요소를 줄이되 상품 오브젝트와 기능은 유지

모바일에서 전체 화면이 잘리거나 클릭 영역이 화면 밖으로 나가지 않도록 한다.

## 10. 접근성 및 사용성

- 모든 클릭 오브젝트는 실제 버튼 또는 키보드 접근 가능한 요소로 구현한다.
- 오브젝트별 명확한 `aria-label`을 제공한다.
- 선택/hover 상태를 색상만으로 구분하지 말고 테두리·텍스트 등도 사용한다.
- 글자 크기는 모바일에서 읽기 쉽게 유지한다.
- 작은 장식 애니메이션은 `prefers-reduced-motion`을 고려한다.
- 오브젝트가 너무 많아 복잡해지지 않도록 카테고리별로 구분한다.
- 처음 진입한 사용자에게 3단계 튜토리얼을 보여준다.
  1. 진열대를 클릭해 상품을 살펴보세요.
  2. 상품을 장바구니에 담아보세요.
  3. 5,000원 안에서 한 끼를 완성해보세요.

## 11. 구현 기술 및 코드 구조

기존 프로젝트의 기술 스택과 파일 구조를 먼저 확인한다. 기존 파일을 불필요하게 전면 재작성하지 않는다.

가능한 경우 다음과 같이 책임을 분리한다.

- `VirtualStoreWorld.tsx`: 전체 가상 편의점 월드
- `IsometricStoreScene.tsx`: 아이소메트릭 매장 그래픽 장면
- `StoreHotspot.tsx`: 클릭 가능한 오브젝트 영역
- `StoreObjectPanel.tsx`: 코너/상품 상세 패널
- `StoreHUD.tsx`: 예산·장바구니·미션 정보
- `StoreCharacter.tsx`: 캐릭터 및 이동 애니메이션
- `VirtualStoreData.ts`: 오브젝트와 카테고리 연결 정보
- 기존 `gs25SampleCatalog.ts`: 상품 데이터 재사용
- 기존 pricing service: 가격 및 행사 계산 재사용

실제 파일명은 기존 프로젝트 구조에 맞춰 조정한다. 새 컴포넌트를 만들기 전에 유사한 기존 컴포넌트가 있는지 확인한다.

### 그래픽 구현 방식

가능하면 SVG 기반 아이소메트릭 장면을 우선 사용한다.

- 바닥과 벽을 SVG 다각형으로 구성한다.
- 진열대, 냉장고, 계산대, 문, 전자레인지 등을 별도 그룹으로 분리한다.
- 클릭 가능한 오브젝트에는 투명한 SVG hit area를 올린다.
- CSS로 부드러운 hover, 클릭, 패널 전환, 캐릭터 이동 효과를 준다.
- 이미지 생성 결과가 있더라도 핵심 클릭 영역은 이미지에 구워 넣지 말고 별도의 인터랙티브 요소로 구현한다.
- SVG/이미지가 로딩되지 않아도 기능이 동작하도록 대체 UI를 제공한다.

외부 이미지 URL을 무작정 사용하거나 깨진 이미지가 나오게 하지 않는다. 현재 프로젝트의 이미지 자산을 우선 재사용한다. 적절한 자산이 없으면 자체 SVG/CSS 일러스트로 제작한다.

## 12. 반드시 작동해야 하는 인터랙션 테스트

아래 항목을 실제로 클릭하고 확인한다.

- [ ] 기존 화면에서 `가상 편의점 입장하기` 버튼을 누르면 월드가 열린다.
- [ ] 외부 입구 화면에서 문을 클릭하면 매장 내부로 들어간다.
- [ ] 라면 진열대를 클릭하면 라면 상품 패널이 열린다.
- [ ] 냉장고를 클릭하면 음료/유제품 패널이 열린다.
- [ ] 행사 코너를 클릭하면 1+1·2+1 상품이 표시된다.
- [ ] 전자레인지 코너를 클릭하면 조리 안내가 표시된다.
- [ ] 계산대를 클릭하면 장바구니 화면이 열린다.
- [ ] 상품을 장바구니에 추가하면 수량과 금액이 바뀐다.
- [ ] 예산 HUD의 남은 금액이 즉시 갱신된다.
- [ ] 예산을 초과하면 초과 상태가 표시된다.
- [ ] 가상 재고보다 많은 수량을 담을 수 없다.
- [ ] 가상 구매 완료 시 재고가 차감된다.
- [ ] 캐릭터 안내를 클릭하면 말풍선이 표시된다.
- [ ] 미션 완료 시 스탬프/별 보상이 표시된다.
- [ ] 모바일에서도 모든 주요 오브젝트를 터치할 수 있다.
- [ ] Gemini API 키나 유료 호출 없이 월드 탐색과 상품 담기가 가능하다.
- [ ] 기존 로그인·추천·레시피 기능이 깨지지 않는다.

## 13. 최종 개발 우선순위

한 번에 모든 기능을 무리하게 변경하지 않는다. 기존 앱을 보존하면서 아래 순서로 개발한다.

### PHASE 1. 가상 월드 비주얼 구현
- 가상 편의점 입장 버튼
- 외부 입구 화면
- 아이소메트릭 매장 내부
- 주요 오브젝트 배치
- `가상 매장` 안내 표시

### PHASE 2. 오브젝트 인터랙션
- 진열대 클릭
- 냉장고 클릭
- 행사 코너 클릭
- 전자레인지 클릭
- 계산대 클릭
- 캐릭터 안내 말풍선

### PHASE 3. 상품 데이터 연결
- 기존 상품 카탈로그 연결
- 코너별 상품 필터
- 상품 상세 패널
- 가상 재고 표시
- 행사 배지

### PHASE 4. 장바구니 및 예산
- 상품 담기 및 수량 변경
- 행사 가격 계산

### PHASE 5. 기존 AI 추천과 연결

- 기존 추천 흐름 연결

## 14. 최종 실행 지시

먼저 현재 프로젝트의 `App.tsx`, 화면 라우팅 구조, 상품 데이터, 가격 계산 서비스, 기존 추천 화면을 확인하라.

그다음 기존 앱의 앞부분과 기능을 보존한 채, 매장 선택 이후에 **레트로 주니어 게임 감성의 아이소메트릭 가상 편의점 월드**를 추가하라.

가장 중요한 것은 다음 세 가지다.

1. 사용자가 `가상 편의점 입장하기`를 누르면 새로운 게임 공간이 열릴 것.
2. 편의점 내부가 실제 한국 편의점처럼 보이며 진열대·냉장고·행사 코너·계산대 등을 직접 클릭할 수 있을 것.
3. 클릭한 오브젝트가 상품 정보, 장바구니, 가격 계산 등 실제 앱 기능과 연결될 것.

단순히 일러스트 한 장을 배경으로 넣는 것으로 끝내지 않는다. 장면의 오브젝트와 실제 인터랙션을 분리해 구현한다.

기존 앱의 로그인, 매장 선택, 추천, 레시피 기능을 삭제하거나 깨뜨리지 않는다. Gemini 유료 API 없이도 가상 월드와 주요 쇼핑 인터랙션이 작동하게 한다.

완료 후 다음을 보고한다.

- 수정·추가한 파일 목록
- 새로 구현한 가상 월드 화면
- 클릭 가능한 오브젝트 목록
- 실제 작동하는 인터랙션
- 기존 앱 기능과 연결된 부분
- 아직 구현되지 않은 부분
- 데스크톱 및 모바일 테스트 결과

**최종 사용자 경험:**
사용자가 앱에서 가상 편의점 버튼을 누르면 작은 게임 속 편의점에 들어온 것처럼 느껴진다. 매장 안을 둘러보고 진열대를 클릭해 상품을 고르며, 5,000원 예산 안에서 나만의 한 끼를 완성한다.

**서비스 슬로건: 5,000원의 선택을 더 쉽고, 맛있게!**
